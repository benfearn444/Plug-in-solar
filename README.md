# Bright Socket storefront prototype

This folder contains the current customer-facing pre-launch site for a UK plug-in solar business.

Open `index.html` in a browser to review the storefront. It is intentionally a catalogue and launch-list experience rather than a live checkout: no product is labelled approved until supplier evidence has been reviewed against the applicable UK framework.

Key working documents:

- `RESEARCH.md` — regulation and supplier research
- `PRODUCT-VERIFICATION-TRACKER.md` — product evidence gate
- `SUPPLIER-OUTREACH.md` — supplier questions and public contact routes
- `COMMERCIAL-ASSUMPTIONS.md` — observed prices and launch model
- `COMPLIANCE-CLAIMS.md` — customer-facing claims rules
- `products.json` — structured candidate catalogue and release gates
- `LAUNCH-READINESS.md` — operational checklist for moving from pre-launch to sales
